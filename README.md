## Features

- **Interactive visualizations** — projectile trajectories, electric field lines, wave superposition, orbital mechanics, all on Canvas 2D
- **KaTeX math rendering** — rigorous notation throughout
- **Exercises with hints & solutions** — from conceptual to calculation-heavy
- **Progress tracking** — saved locally in your browser
- **Zero dependencies** — just open the link and learn
